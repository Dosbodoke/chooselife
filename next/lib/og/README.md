# Shared Open Graph images

Highline and news image routes use the Photo first layout, selected on 7 October 2026. Both output 1200 × 630 PNGs with Geist typography, Chooselife branding, a category label, and a gradient over the photograph. Highlines use their cover photo when available, with the local highline-og.jpg as a fallback. News uses that local photo.

The design study and selection are preserved on the local throwaway branch `codex/prototype-opengraph`, commit `b7bd6fa`. That branch contains all four alternatives and its local preview command. The prototype route and switcher do not belong in the implementation.

Font files in assets/og are from the existing Geist dependency and retain their SIL Open Font License.
